# Request Rules Template

Copy one line into a future request when you want the source folder used.

## Common Rules

- Use the full source folder as background, but only update Section 00 and Section 11.
- Use research as background only; do not mention source names.
- Use only high-priority sources from `Research_Index.md`.
- Use the Art Playbook and templates to improve process language.
- Use research conversations to improve strategy and framing.
- Do not use archived examples unless I ask for case studies.
- Keep language simple and presentation-friendly.

## Suggested Request Format

`Use C:\Users\rimas\OneDrive\Desktop\FC_CA_Playbook_Research as source context. Use research as background only, do not mention source names, and update only [section name]. Keep the wording simple and practical.`

## Source Priority Defaults

- High: use by default when relevant.
- Medium: use when it supports the requested section.
- Low: use only for visual examples, optional support, or when specifically requested.

## AI Use Rule

AI can help summarize, sort, draft, and structure. Creative direction and final decisions stay human-led.
